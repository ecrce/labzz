Images were converted between BMP, JPG, and GIF using IrfanView. JPG compression reduced file size but introduced visible artifacts and slight blurring. Converting JPG back to BMP increased file size without restoring quality. GIF conversions reduced color depth, causing banding and dithering. Repeated conversions further degraded image quality.

Conclusion: Lossy compression and palette reduction produce permanent changes relevant to forensic analysis
